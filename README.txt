梦想成为单片机大手  v1.0
单片机开发、烧录、串口与调试工具统一启动器
======================================================================

一、这是什么
----------------------------------------------------------------------
“梦想成为单片机大手”是一个 Windows x64 工具启动器。它把固件烧录、
串口/SSH、开发环境、调试分析、驱动和常用效率工具放进同一界面，并根据
本机安装情况自动识别可用程序。

启动器本身是原创程序，不包含、也不转载任何第三方软件安装包。清单中的
软件通过官方网址获取；已经安装的软件、绿色便携版和用户自行添加的程序，
可以一键识别并启动。

主要功能：
  - 47 款软件的统一清单与中文分类
  - 自动扫描已安装软件、注册表 Uninstall 和 App Paths
  - 自动扫描 tools 目录中的绿色版
  - 搜索、收藏、最近使用、仅显示本地可用
  - 一键启动、官方网站、工具所在目录
  - 管理员权限启动需要 UAC 的驱动或厂商工具
  - “添加本地程序”导入任意 EXE
  - 从 EXE 读取真实图标
  - 设置随身保存，整个目录可移动


二、直接运行
----------------------------------------------------------------------
双击：
  梦想成为单片机大手.exe

系统要求：
  Windows 10 / 11 x64

程序已打包为自包含 EXE，不需要另行安装 .NET。首次运行时 Windows
SmartScreen 可能提示“未知发布者”，这是因为本工具没有商业代码签名证书。
确认文件来自本交付包后，可选择“更多信息”并继续运行。

目录结构：
  梦想成为单片机大手.exe   主程序
  catalog.json             软件清单与官网地址
  README.txt               本说明
  tools\                   外部工具和便携版
    firmware\              固件烧录
    terminal\              串口终端 / SSH
    development\           开发环境
    debug\                 调试分析
    driver\                驱动与检测
    utility\               实用工具
  data\                    自动生成的设置、收藏和自定义工具
  source\                  可修改的 WPF 启动器源码

建议保留整个文件夹，不要只移动 EXE。catalog.json 必须和 EXE 在同一层。


三、怎么放入自己的软件
----------------------------------------------------------------------
推荐方式：使用“添加本地程序”。

  1. 启动工具箱，点击右上角“添加本地程序”。
  2. 选择任意 .exe。
  3. 程序会读取文件名和版本信息，自动加入“我的工具”。
  4. 双击卡片或点击“启动”即可运行。

绿色版方式：

  1. 在清单详情中点击“所在目录”，或者手动打开对应分类目录。
  2. 将便携版解压到该工具自己的子目录。
  3. 回到工具箱点击右上角“重新扫描”。
  4. 扫描器会优先按清单中的 executableNames 查找 EXE；
     找不到指定名称时，会尝试目录内第一个非卸载类 EXE。

清单默认目录示例：
  Xshell 8         tools\terminal\Xshell8\
  balenaEtcher    tools\firmware\BalenaEtcher\
  Bandizip        tools\utility\Bandizip\

如果软件安装在其他位置，“添加本地程序”也可以直接导入，不需要复制。
路径会保存在 data\settings.json 中。

注意：
  - 商业版 Xshell、Bandizip、Keil MDK、IAR 等请使用自己合法取得的版本。
  - 驱动、烧录器和厂商工具请优先使用厂商官网的当前版本。
  - 本工具不会静默安装驱动，也不会绕过 UAC。
  - 点击“获取”只打开官方页面，不自动下载或安装。
四、界面操作
----------------------------------------------------------------------
搜索
  可搜索软件名、厂商、分类、说明和标签。支持空格分隔多个关键词。

分类
  固件烧录、串口终端、开发环境、调试分析、驱动与检测、实用工具。
  “全部工具”“收藏”“最近使用”“本地可用”“我的工具”是动态视图。

收藏
  点击卡片右上角的星标。设置会写入 data\settings.json。

最近使用
  只有通过本工具箱成功启动的本地程序才会进入“最近使用”。

仅显示本地可用
  隐藏尚未识别的程序，只保留能够直接启动的本地软件。

获取
  未检测到本地程序时显示“获取”，点击后用默认浏览器打开官方下载页。

管理员权限
  清单中 RequiresAdmin 为 true 的 EXE 会通过 UAC 请求管理员权限。
  如果取消 UAC，界面会提示未启动。


五、封装机制说明
----------------------------------------------------------------------
参考“图吧工具箱”的思路，核心不是把多个软件重新打包成一个可执行文件，
而是“统一入口 + 分类目录 + 软件清单 + 按需启动”：

  1. catalog.json 描述每个软件的名称、分类、官网、下载地址、
     目录、可执行文件名、检测名、标签和权限要求。
  2. 启动器读取清单并生成分类和卡片。
  3. 扫描器从以下位置寻找本地程序：
       - tools\<分类>\<工具目录>
       - 注册表 Uninstall 的 DisplayIcon / InstallLocation
       - 注册表 App Paths
       - 用户手动添加的路径
  4. 找到 EXE 后，启动器用 ShellExecute 启动原程序，
     需要管理员权限时附加 runas。
  5. 未找到 EXE 时，启动器只打开官网，不接管第三方安装流程。

优点：
  - 不修改原软件，不破坏签名，不改变厂商更新方式
  - 绿色版、安装版、自定义路径可以共存
  - 清单可编辑，增减软件不需要重新编译启动器
  - 适合封装几乎任何有独立 EXE 的 Windows 桌面软件

这个机制适合：
  - 厂商烧录器、IDE、串口终端、SSH 客户端
  - 驱动安装器、检测器、逻辑分析仪软件
  - 绿色工具、命令行工具及其 GUI
  - 企业内部自研工具

不适合直接封装：
  - 只能通过浏览器或云平台使用的服务
  - 没有可启动本地入口的插件
  - 需要启动器代做授权的商业软件
  - 不允许再分发的闭源安装包

第三方软件的版权、许可和更新责任归各自厂商所有。
六、修改软件清单
----------------------------------------------------------------------
catalog.json 的 tools 数组中，每一项都可配置。最小示例：

  {
    "id": "my-tool",
    "name": "我的烧录器",
    "category": "固件烧录",
    "summary": "一句话简介",
    "description": "较完整的说明",
    "vendor": "厂商名称",
    "license": "许可说明",
    "homepage": "https://example.com/",
    "downloadUrl": "https://example.com/download",
    "folder": "firmware/MyTool",
    "executableNames": [ "MyTool.exe" ],
    "detectNames": [ "My Tool" ],
    "requiresAdmin": false,
    "glyph": "\uE950",
    "accent": "#2DD4BF",
    "tags": [ "烧录", "USB" ]
  }

字段说明：
  id               唯一标识，不要和已有项重复
  name             界面显示名称
  category         必须对应已有分类
  folder           tools 下的相对目录，分隔符用 /
  executableNames  扫描和启动时查找的 EXE 文件名
  detectNames      注册表 DisplayName 包含的文本
  requiresAdmin    启动时是否请求管理员权限
  downloadUrl      未安装时“获取”打开的官方页面
  homepage         “官网”按钮打开的页面

修改后保存，重新启动工具箱或点击“重新扫描”。

八、常见问题
----------------------------------------------------------------------
1. 提示找不到 catalog.json
   请确认 catalog.json 与 EXE 在同一目录。不要只复制 EXE。

2. Xshell 或其他软件已经安装，但仍显示“获取”
   先点“重新扫描”。如果仍未识别，点“添加本地程序”直接选择 EXE。
   某些版本的实际 EXE 名可能与清单不同，这是正常的。

3. 点击“启动”后没有反应
   检查 EXE 是否仍存在、是否被杀毒软件隔离、路径是否包含失效盘符。
   需要管理员权限的工具会弹出 UAC；取消 UAC 时不会启动。

4. 驱动安装后设备仍不出现
   重新插拔设备，打开设备管理器检查驱动是否匹配芯片型号。
   CH340/CH341、CP210x、FTDI 是不同芯片，不能混装驱动。

5. 便携版搜索不到
   把 EXE 放入对应 tools\分类\工具名 目录，或直接用“添加本地程序”。
   扫描器不会执行未知 EXE，只会读取文件图标和版本信息。

6. SmartScreen 或杀毒软件误报
   单文件自包含程序首次运行会释放运行时组件，可能触发启发式提示。
   可使用 source 目录重新编译，或用离线扫描工具检查后再运行。

7. 设置会不会跟着移动
   data 和 tools 与 EXE 同目录，整体移动文件夹即可。
   如果自定义工具使用绝对路径，移动后需要重新添加。


九、说明与边界
----------------------------------------------------------------------
本工具箱的封装目标，是让开发者在一个入口里找到和管理工具，不改变第三方
软件本身，也不以任何方式绕过授权、签名、付费或更新机制。

本交付包不包含指定商业软件的安装包。用户需要从官方渠道获取软件，并遵守
各厂商许可。第三方名称和商标归各自权利人所有。

启动器源码位于 source 目录，可自行修改清单、分类、图标和扫描规则。
